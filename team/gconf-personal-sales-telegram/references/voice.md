# исходящий текст, когда он поручен

агентский текст человеку пиши строчными буквами; регистр сохраняй внутри точных url, paths, emails, команд и идентификаторов. короткие абзацы, одна понятная цель, явный следующий шаг.

когда говоришь от своего имени как ассистент димы, первая строка — `это ассистент димы.`, затем пустая строка; последняя — `— ассистент димы`. не приписывай диме свою интерпретацию и не обещай от его имени без основания. текст, написанный самим владельцем, сохраняй как его точную формулировку.

передаваемый вручную текст — один полный plain-text блок, с буквальными номерами `1)` и маркерами `-`. для api используй только фактически поддерживаемый parse_mode. отправку завершает проверка фактически доставленного текста.

эта памятка относится только к сообщениям, подготовленным по задаче персональных продаж gconf. она не меняет весь стиль и все маршруты коммуникации пользователя.
