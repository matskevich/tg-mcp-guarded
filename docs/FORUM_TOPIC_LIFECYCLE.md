# обратимое управление темами

`tg_edit_forum_topic` переименовывает, закрывает, скрывает общую тему или
закрепляет точную тему личного форума создателя. история не удаляется.
требуются точный id группы, id темы и независимо прочитанный `expected_title`.
allowlist, dry-run, одноразовый approval code, exact process confirmation и
idempotency сохраняются. все изменения связаны с одним preview payload.

telegram требует отдельный rpc для закрытия, изменения названия и скрытия.
частичный/неизвестный результат блокирует повтор до независимой сверки.
mutating rpc не повторяются автоматически после таймаута. принятый ответ
инструмента требует отдельного `tg_get_forum_topics`: индекс списка может
отставать, поэтому reader дочитывает актуальное состояние по точным ids.

скрытие разрешено только для общей темы с id 1. обычные архивные темы остаются
видимыми закрытыми; не обещать их удаление или сокрытие. операция доступна
свежему native action mcp; наличие в исходниках не доказывает её доступность
во всех облачных клиентах. общий capability release принимается отдельно.
